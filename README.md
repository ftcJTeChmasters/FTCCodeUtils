# FTC Code Utils

Visual Studio Code extension for Team 32722.

## Features

- Dedicated VS Code sidebar
- Automatic FTC Java file generation
- Automatic headers
- OpMode generator
- Subsystem generator
- Java class generator
- Standardized project structure

## Development

Install dependencies:

```bash
npm install
```

Compile:

```bash
npm run compile
```

Package as a VSIX:

```bash
npm run package
```

Then install the generated `.vsix` file in VS Code using:

Extensions → `...` → Install from VSIX...
